# Ультразвуковой датчик присутствия (отложено, для Миди)

Статус: **не делаем для Мини 3**, оставлено как заготовка для Станции Миди (`cucumber`) и других колонок, у которых динамики и
микрофоны нормально передают 18–20 кГц. Всё, что понадобится, уже разобрано.

## Что есть в `libyandex_evil.so`
Библиотека (`/system/vendor/quasar/libs/libyandex_evil.so`, копия в `ref/evil/`) содержит сонар:

```c
int YandexVqeC_UltrasoundSonar_Create(Sonar **out, const Config *cfg);
int YandexVqeC_UltrasoundSonar_AddChannelData(Sonar *s, bool flag, a, b, c);   // flag + три аргумента: указатель на PCM, число кадров, ...
int YandexVqeC_UltrasoundSonar_Process(Sonar *s, int *result);                // результат классификатора
int YandexVqeC_UltrasoundSonar_Reset(Sonar *s);
int YandexVqeC_UltrasoundDetector_Create(Detector **out, const Config *cfg);   // «слушатель» без излучения
int YandexVqeC_UltrasoundDetector_AddChannelData(...);  int YandexVqeC_UltrasoundDetector_Process(Detector *, int *);
```
Форма API получена декомпиляцией в Ghidra (`ref/evil/ultrasound_decomp_part.c`, скрипт `ref/evil/ghidra_scripts/DecompileExports.java`).

Как это работает по строкам и структуре: внутри `UltrasoundSonarAnalyzer` есть **корреляторы** (`runCorrelators`) по известной
излучаемой последовательности, то есть сонар **сам ничего не играет**: приложение должно проиграть ультразвуковой сигнал в
динамик и подать в `AddChannelData` и эталон, и запись микрофона.

Чего нет: в стоковой конфигурации (`quasar.cfg`, `launch.json`, `vqe_models/`) ультразвук нигде не включён, поэтому готового
формата конфига (`Config`) и самого сигнала у нас нет. Их нужно подобрать (разбор аргументов в Ghidra: функции `FUN_00189dd0`
(создание анализатора) и `FUN_00189e44` (добавление данных) в `ultrasound_decomp_part.c`).

## Что делать, когда понадобится
1. Проверить железо колонки: проиграть чистый тон 19 кГц на 48 кГц через `aplay` и записать микрофоны (`arecord -D default -c 4 -r 48000`),
   посмотреть спектр (есть ли пик 19 кГц). У Мини 3 динамик и микрофоны не проверены, у Миди (96 кГц захват!) шансов больше.
2. Два пути:
   - **Свой датчик (проще).** Излучать тихий тон около 19–20 кГц (поверх музыки) и по спектру микрофона (изменение амплитуды и
     допплер от движения) определять присутствие. В прошивке уже есть анализатор спектра (`audio/spectrum.cpp`); тон добавить
     через ALSA-плагин (как эквалайзер `alsa/lostoseq.c`).
   - **Стоковый сонар.** Разобрать структуры `Config`, воспроизвести сигнал библиотеки, подавать данные из `frontend.cpp`
     (там уже есть `YandexVqeC_*` и канал опорного сигнала динамика).
3. Результат отдавать как плагин «Присутствие» (событие `presence` + плитка на главной), см. `docs/lostos-architecture.md`.

## Оговорки
- Тон около 19 кГц слышат часть людей и животные (кошки, собаки): нужен выключатель и тихий уровень.
- Изучение библиотеки делается только на своей колонке и только как статический разбор.
